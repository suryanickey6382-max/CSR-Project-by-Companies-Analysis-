 **CSR PROJECT BY COMPANIES**

**Project Title**

A data analysis project focused on Corporate Social Responsibility (CSR) projects 
carried out by companies across different states and districts in India.

**Project Description**

This project analyses a CSR projects dataset containing information about companies, 
project names, development sectors, geographic locations, company classification, 
listing status, project outlay, and actual spending. 

The objective is to organize, explore, and understand CSR investment patterns and 
identify useful insights from the available data.
